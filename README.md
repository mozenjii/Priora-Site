# Priora Website

Investor-facing landing site for **Priora**, an AI copilot for prior authorization and denial appeals in healthcare.

## Live Site

- Vercel: [https://prioraai.vercel.app](https://prioraai.vercel.app)

## Project Location

- Site root: `site/priora-landing`
- Main page: `site/priora-landing/index.html`
- Styles: `site/priora-landing/styles.css`
- Client-side behavior: `site/priora-landing/main.js`
- Thank-you page: `site/priora-landing/thanks/index.html`

## What The Site Covers

- What Priora is and who it is for
- Why prior authorization is a high-friction healthcare workflow
- A simple product flow: upload, match, draft
- Market proof and ROI logic
- Revenue impact for clinics, payers, billing teams, and revenue-cycle operators
- Business model and contact section

## Stack

- Static HTML, CSS, and vanilla JavaScript
- Google Fonts: Manrope and Space Grotesk
- Responsive layout for desktop and mobile

## Local Use

Open `site/priora-landing/index.html` directly in a browser, or serve the `site/priora-landing` directory with any static file server.

## Deployment

- Current production deployment is on Vercel
- Project name: `priora-landing`
- Vercel project config lives in `site/priora-landing/.vercel/project.json`

## Notes

- The contact form forwards requests to `epochesofficial@gmail.com`.
- The site is intentionally minimal and professional so it works for investors, clinics, and industry reviewers.
